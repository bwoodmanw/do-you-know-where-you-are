# Thanksgiving toon picture workflow

Use this workflow to create the front and back toon pictures for the four
Thanksgiving skins, the Gobbler host, and the runaway turkey. Make the
pictures in table order. Each back view uses the front view made immediately
before it as its only reference. Front views for the Gobbler and runaway
turkey use no reference picture.

```
create new workflow to create images based on the [Picture Standard], [Reference] and [Picture]. For each picture, attach every [Reference] picture listed, in that order (none when it says none), then save to "C:\Users\bwood\OneDrive\Documents\Kids Games\Do You Know Where You Are\art\model-input\[file name]". For example, C:\Users\bwood\OneDrive\Documents\Kids Games\Do You Know Where You Are\art\model-input\chef-brainy\front-toon.png. Create the folder if it does not exist.
The [Picture Standard] will be included with every picture prompt. The [Picture] prompt is added to [Picture Standard] and changes per prompt. The [Reference] and [file name] are defined per picture. Make the pictures in the order of the table: each back view uses the front view made just before it as its reference.
```
