## What it is

**Escape Crew** is a co-operative horror-escape game on **Roblox** for ages 8+.
A party of 1-6 kids picks characters with skills and escapes one floor of a
haunted building before a host catches them. Each escape unlocks the next
floor. Design: `GAME_DESIGN.md` (sections 0 and 0b); the agreed build plan
and what is done: `ROADMAP.md`; floor-plan rules: `MAP_PLAN.md`.

## How a game runs

1. Lobby: a party leader stands on a circle (friends walk in or are invited;
   the party closes after 3 minutes). Solo: choose a floor, then Start.
   The leader opens the **map screen**: building cards, then floor cards with
   pictures; everyone votes at once (votes and voter names shown); the
   leader presses Done and Start.
2. Party House: everyone picks a character (nobody defaults). The host and
   clock wait until all have chosen, or 2 minutes (then random). Characters
   lock once the clock starts.
3. Find 3 clue balloons -> the colour code; locked doors open with a key
   (search spots) or Tinker's pick; reach the exit. A random host per floor
   (half the time the building's own). Caught = close-up, cage; friends free
   you (3.5 s hold, Patch 1.75 s).
4. Results wait for the scare to finish; Play again or Back to lobby.

## Lessons (keep)

- Don't rename the start place. Teleports and invites only work live.
- Rojo: Lobby = 34873, Party House = 34872; the projects are locked to their
  place ids and the scripts warn "WRONG PLACE" in F9. Rojo started from
  Claude's shell dies after ~2 h; Brent can run it in his own PowerShell
  (commands in `roblox/README.md`).
- FredokaOne lacks some symbols: use "X" in GothamBlack, "-", 🔄, 🔺.
- Other players only see a character run if the server makes its Animator.
- Patch scripts: Write tool, assert anchors, `.tmp` + `os.replace`; a Python
  `""""` next to a quote mis-closes strings - check the compile.
- Meshy faces are soft because of the source picture; use one big front image.
- `re.sub` replacements collapse backslashes - use a lambda.
- Imported heads may face backwards: aim by the root's LookVector.
- Hud.client.luau hit Luau's 200-locals limit in Studio (7 Oct: every button
  vanished) although `luau-compile` passed - Studio compiles at debug level 2:
  always check with `luau-compile --null -g2`. Top level now ~131 locals; wrap
  new HUD code in `do ... end` blocks.
- Rojo servers that run for a day can stop noticing file changes: restart them
  and reconnect the Studio plugin when Studio does not match the code.
