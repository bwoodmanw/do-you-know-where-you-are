## Picture Standard

This is for a kids' co-op escape game for ages 8 and up: friendly, funny, cozy and a little spooky, never scary. Rich, polished 3D animated-movie style (soft light, glossy rounded shapes), in the same style as the LAST attached picture. Keep every character exactly as in its attached picture (face, hair, eye color, skin tone, clothes and colors). No text, no letters, no numbers, no logos or brand marks. Nothing that looks like a famous character from a film, cartoon or game.

## Run

1. Resolve both roots relative to this project. Check every reference exists and inspect each distinct reference with `view_image` before generating. Create missing output folders.
2. For each asset in table order, submit its complete saved `prompt` to the built-in image generator. Use `referenced_image_paths` containing the absolute paths of EVERY row reference in the listed order. Set `transparent_background` to false. Use one generation call per picture.
3. For the event image, attach Crumbles first, Nutmeg second, Holly third, and the Harvest Barn fourth. The first three supply character identity; the LAST supplies rendering style. For each building or floor image, the sole reference supplies style, angle, framing and lighting. Keep the subject specified by the Picture prompt.
4. Generate the event image square and the five map images wide with an exact 16:9 aspect ratio. Keep Nutmeg left of Crumbles within the right two thirds so the left third remains darker sky and snow only. Keep the factory clock face free of numerals and letters. Do not add a title.
5. Inspect each generated image for its row-specific `review_checks`, the shared Picture Standard, character fidelity where applicable, and any unwanted text, logos or recognizable famous-character resemblance. Correct defects before selecting a final image.
6. Copy the selected generated PNG from its returned source path to `output_root/file_name`. Do not rely on a generator destination-path argument. Preserve existing assets on reruns unless replacement is explicitly requested; otherwise use a versioned sibling and record that actual destination.
7. Verify each saved file decodes as PNG and has the required aspect ratio (width equals height for the event; width times 9 equals height times 16 for maps). If generation returns a different ratio, correct it before accepting the asset. Do not silently crop away requested details or stretch the image.
8. After each save, update the asset status and record the submitted prompt, ordered absolute references, generated source path, saved destination, actual dimensions, visual review outcome and SHA-256 in `art/roblox-store/christmas-event-map-generation-report.json`. Mark an asset complete only after review and file verification.
