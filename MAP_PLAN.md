# Party House v2 - more rooms, locked doors, keys (proposal, 6 Oct 2026)

Brent asked for more rooms per map, more walls, objects and decorations to
distract from the clues, and a fairer Tinker. Not built yet - waiting for a yes.

## Tinker, redone

- Tinker can **no longer open the exit door**. The exit only opens with the
  3-colour code.
- The house has **2-3 locked inner doors** on the way to the exit (rooms you
  must pass through, or rooms holding a clue).
- **With Tinker in the team:** she picks a locked door (hold 4 s, a click
  sound, the door swings open). Her ladder upgrades make it faster.
- **Anyone else:** needs a **key**. Each round, every locked door has one key
  hidden in a random searchable object somewhere else in the house (drawer,
  toy chest, cake box, coat pocket, vase...). Searching takes a 2 s hold and
  makes a little noise, so the host may come. One key opens one door.
- Solo players without Tinker still always have a way through (the keys).

## Bigger house

- About **10 rooms** instead of 6, on a 40 x 30 grid (the code is not tied to
  the size): Front Hall (start), Corridor (exit door), Parlour, Kitchen,
  Pantry, Dining Room, Library, Game Room, Music Room, Bathroom, Conservatory.
- **More walls inside rooms:** half walls, shelves and screens that make small
  dead ends and corners to hide behind.
- **Decorations:** streamers, framed pictures, rugs, lamps, cobwebs, carved
  pumpkins, party hats on tables, a cake, toy piles.
- **Decoys:** extra balloons and presents that are just air ("Nothing in this
  one!"), and searchable objects with no key. The clues are the same three,
  so the decoys slow you down without making it unfair.
- The corner map, hiding spots, host patrol route and furniture spots
  (`Props.SPOTS`) are redrawn for the new layout.

## Order of building

1. New layout (HouseMap) + walls + locked doors + keys + Tinker change.
2. Decorations and decoys.
3. Balancing: escape timer per difficulty for the bigger house.
