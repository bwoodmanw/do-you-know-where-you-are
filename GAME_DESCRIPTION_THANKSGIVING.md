# Game description: Thanksgiving (4 Nov 2026)

Paste into Creator Hub > Creations > Escape Crew > Configure > Basic Info >
Description (Roblox allows 1,000 characters; this is about 880). Swap back
to a Christmas one on Dec 1.

```
THANKSGIVING UPDATE: the Harvest Barn, the Turkey Roundup, golden feathers and 4 new heroes!

Can your crew escape before the host catches you? Team up with up to 6 friends or go solo, pick a hero with a special skill, crack the color code and get out!

THANKSGIVING
- The Harvest Barn: sneak past the Gobbler and round up the runaway turkeys
- Catch 50 turkeys for the Turkey Wrangler badge
- Every turkey caught in every server fills the Feast Meter - unlock rewards for everyone and the Lobby feast!
- Find golden feathers on every floor and spend them in the Feather Shop on Thanksgiving skins

NEW HEROES: Cloud hides your crew in fog, Clone copies a friend's skill, Harmony sings the host to sleep, and Holly leaves a slippery peppermint trail. Unlock them by escaping!

HOW TO PLAY
- Pop clue balloons to learn the door code (some are tricks!)
- Search drawers and boxes for keys and surprises
- Run, hide and crawl through vents when the host comes
- Free caught friends from the cage
- Level up your hero for new powers
```
